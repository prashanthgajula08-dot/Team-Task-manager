================================================================
  TEAM TASK MANAGER
  A full-stack team task management application
================================================================

LIVE URL
--------
  https://team-task-manager-1-6ihe.onrender.com

DESCRIPTION
-----------
  A full-stack task management app where teams can create projects,
  assign work, and track progress with role-based access control
  for ADMIN and MEMBER roles.

FEATURES
--------
  - Signup and login with secure password hashing
  - Cookie-based JWT authentication
  - Project creation and team membership management
  - Task creation, assignment, priority, due dates, and status tracking
  - Dashboard with assigned work, overdue tasks, and summary metrics
  - Role-based access control:
      ADMIN  : create projects, add teammates, assign tasks,
               and update any task in their project
      MEMBER : view shared projects and update status of
               tasks assigned to them
  - SQLite database with relational foreign-key constraints

TECH STACK
----------
  Backend   : Node.js, Express
  Frontend  : HTML, CSS, Vanilla JavaScript
  Database  : SQLite (node:sqlite built-in, requires Node 22.5+)
  Auth      : JWT stored in HTTP-only cookies

LOCAL SETUP
-----------
  1. Install dependencies:
       npm install

  2. Create your environment file:
       copy .env.example .env

  3. The database schema is created automatically on first app start.

  4. (Optional) Load demo data:
       npm run db:seed

     Demo credentials after seeding:
       Admin  : admin@demo.com  / password123
       Member : member@demo.com / password123

  5. Start the development server:
       npm run dev

  6. Open in browser:
       http://localhost:3000

API ENDPOINTS
-------------
  Auth:
    POST  /api/auth/signup
    POST  /api/auth/login
    GET   /api/auth/me
    POST  /api/auth/logout

  Projects:
    GET   /api/projects
    POST  /api/projects
    GET   /api/projects/:projectId
    POST  /api/projects/:projectId/members
    POST  /api/projects/:projectId/tasks

  Tasks:
    PATCH /api/tasks/:taskId

  Dashboard:
    GET   /api/dashboard

  Health:
    GET   /health

RENDER DEPLOYMENT (FREE TIER)
------------------------------
  Platform  : Render (https://render.com)
  Plan      : Free
  Service   : Web Service (Node.js)

  Environment Variables set on Render:
    NODE_ENV     = production
    NODE_VERSION = 22.15.0
    JWT_SECRET   = <auto-generated secure value>
    DATABASE_URL = file:./data/team-task-manager.db

  Build Command : npm install
  Start Command : npm start
  Health Check  : /health

  NOTE: On the free tier, the service spins down after 15 minutes
  of inactivity. The first request after sleep may take 30-50
  seconds to respond. Data resets on each redeploy (no persistent
                                                      disk on free plan).
